# 2.0 寸 240×320 TFT SPI 模组（ST7789V2）资料与示例

**English：** [`README_EN.md`](README_EN.md)

---

> 本仓库提供该模组的 **ESP-IDF 示例工程**。数据手册与规格书待后续补充至 `docs/`。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 2.0 英寸 **TFT**（IPS），分辨率 **240×320** |
| 接口 | **SPI** |
| 驱动芯片 | **ST7789V2** |
| 规格标识 | 产品资料中常用 **`2.0-tft-240x320-spi-st7789v2`** 表示本规格 |
| 同尺寸其他规格 | 2.0″ **460×460 AMOLED** 见 **`2.0-amoled-460x460-qspi-co5300`**、**`2.0-amoled-460x460-mipi-co5300`**，面板类型与接口不同、独立维护 |
